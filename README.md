# ⚡ FREAK SHOP - E-Commerce

Proyecto desarrollado para la carrera de Programación en la **UTN**.

### 🚀 Tecnologías utilizadas:
* React + Vite
* CSS Modules (Estética Cyberpunk/Neón)
* Lucide React (Iconos)
* Context API (Gestión de Carrito y Alertas)
* LocalStorage (Persistencia de datos)

### 🛠️ Funcionalidades:
* Carrito de compras funcional.
* Panel de Administrador para gestión de tickets y usuarios.
* Sistema de alertas personalizadas (estilo SweetAlert).
* Registro y Login con validaciones de seguridad.
